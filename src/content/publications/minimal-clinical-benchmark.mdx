## The question

Before crediting an MRI-based deep learning model with predicting Alzheimer's, what would a trivial model using only age and a cognitive test score achieve?

## What I did

Built a minimal baseline classifier using just two easily-collected clinical variables — patient age and MMSE (Mini-Mental State Examination) score — and evaluated its predictive performance on the same task imaging models are usually benchmarked on.

## Result

The minimal baseline performs non-trivially well, which sets a concrete bar: an imaging pipeline needs to clear this simple benchmark by a meaningful margin to justify its added cost and complexity.

## What it means

This is a benchmarking paper, not a competing method — it exists so that future imaging-based AD papers (including my own) have an honest floor to compare against, instead of only comparing against each other.
